Create the “Legion Runner” GitHub App

This page opens GitHub’s App-creation screen with every permission pre-filled. It runs entirely in your browser and sends nothing anywhere except the GitHub form you submit. After you confirm, generate a private key and copy the App ID, then install the App on your org(s).

Permissions it will request:

ScopePermissionLevel
RepositoryAdministrationRead & write
RepositoryActionsRead & write
RepositoryMetadataRead
OrganizationSelf-hosted runnersRead & write
Who owns the App? The App is owned by one account. To install it across several of your orgs, keep it public (below) and install it on each.
Visibility

App names are globally unique. If “Legion Runner” is taken, GitHub will ask for another name — it doesn’t matter to the runner. After creating: generate a private key, copy the App ID, and install the App. Then add LEGION_E2E_APP_ID / LEGION_E2E_APP_PRIVATE_KEY as repo secrets to enable the live e2e.
